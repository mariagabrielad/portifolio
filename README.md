# Checkpoint 6 --- Entrelinhas: Clube do Livro

Landing page criada para apresentar um clube de leitura de forma
acolhedora, elegante e contemporânea.

## Estrutura do projeto

-   `index.html`: página principal.
-   `assets/`: imagens utilizadas na landing page.
-   `documentacao/`: processo de criação, referências, identidade
    visual, prompts, correções e análise final.

## Antes de entregar

1.  Confira se o `index.html` abre corretamente no navegador.
2.  Substitua imagens provisórias pelas imagens escolhidas.
3.  Teste todos os botões, links e controles do carrossel.
4.  Complete a documentação de correções com os problemas que realmente
    aconteceram durante o desenvolvimento.
5.  Inclua o link do repositório e o link do deploy na seção de
    resultado final.
