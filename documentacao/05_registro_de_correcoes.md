## Checklist de testes

-   [ ] O menu leva às seções corretas.
-   [ ] Os botões têm uma ação clara.
-   [ ] Os links abrem o destino correto.
-   [ ] Os controles do carrossel funcionam, se houver.
-   [ ] As imagens carregam corretamente.
-   [ ] Os textos permanecem legíveis em telas menores.
-   [ ] Não há rolagem horizontal inesperada no celular.
-   [ ] Não há erros visíveis no console do navegador.

Registre o resultado real de cada teste. Se algo falhar, corrija e
documente a alteração.
